# ⌨️ 按键绑定速查

## Surf 配置通用键位（surf110/SURF210/autoexec）

| 按键 | 功能 | 备注 |
|------|------|------|
| **W** | 前进（空移） | 松 S + 按 W |
| **S** | 后退（空移） | 松 W + 按 S |
| **A** | 左移（空移） | 松 D + 按 A |
| **D** | 右移（空移） | 松 A + 按 D |
| **Q** | 左转向（+mTurnLeft） | 低速或高速取决于当前档位 |
| **E** | 右转向（+mTurnRight） | 同上 |
| **Space** | 大跳（Crouchjump） | 蹲+跳+松方向+落地自动切低速 |
| **R** | 回存点 + 切高速 | sm_teleport + turn_speed_high |
| **V** | 手动切回低速 | 备用 |
| **N** | net_graph 开关 | 按一次显示，再按关闭 |
| **Mouse1** | 攻击（默认） | 不绑定（triekz 除外） |
| **Mouse2** | 跳跃 | 纯跳 |
| **Mouse3** | 解卡 | sm_stuck |
| **Mouse4** | 重试 | sm_restart |
| **X** | 重试 | sm_r |
| **C** | 保存位置 | sm_saveloc |
| **F** | 传送至保存点 | +teleport |
| **Z** | 去他人位置 | sm_goto |
| **T** | 旁观模式 | sm_spec |

## trikz.cfg 专用键位

| 按键 | 功能 |
|------|------|
| **Mouse1** | +macro（宏操作） |
| **Mouse2** | +jump |
| **R** | sm_block |
| **F** | sm_tele |
| **N** | net_graph 开关 |

## 操作逻辑示意

```
     [W] 前进
      ↑
[A] ← ┼ → [D]     ← 空移 WASD
      ↓
     [S] 后退

[Q] ← 转向 → [E]   ← 高速/低速两档

[Space] 大跳       ← 落地自动切低速
[R] 回存点          ← 自动切高速
[N] net_graph      ← 开关切换
```
