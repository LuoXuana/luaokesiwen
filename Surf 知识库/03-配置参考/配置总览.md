# ⚡ 配置总览

## 文件一览

| 文件 | 低速 | 高速 | 定位 |
|------|------|------|------|
| `surf110.cfg` | 110 | 293 | 通用 surf，最常用 |
| `SURF210.cfg` | 210 | 293 | 需要更快转向的图 |
| `autoexec.cfg` | 60 | 293 | 通用启动配置 |
| `trikz.cfg` | 固定 210（无 Q/E） | - | Trikz 模式专用 |

## 通用配置结构

所有 surf 配置（surf110/SURF210/autoexec）共享以下结构：

```
[1] 网络设置        ─  100 tick 优化
[2] 多核渲染        ─  mat_queue_mode -1
[3] 视角 & 手臂     ─  cl_bob 0, viewmodel_fov 80
[4] 准星            ─  青色准星
[5] 音频            ─  低延迟音频
[6] FPS 优化        ─  关闭阴影、光照、物理等
[7] 转向系统        ─  Q/E 高低速切换
[8] 空移            ─  WASD null movement
[9] 按键绑定        ─  所有按键
[10] 杂项           ─  hud_fastswitch 等
[11] 初始状态       ─  默认高速 + net_graph 关闭
```

## 通用修复项（vs 原版）

| 项目 | 原版 | 优化版 | 原因 |
|------|------|--------|------|
| `rate` | 786432 | **30000** | 786432 是 CS:GO 的值，CS:S 上限 30000 |
| `fps_max` | 1100 | **600** | >600 FPS 时 Source 物理引擎可能抖动 |
| Restore alias | 空 | **双清** | 防止双键齐按卡方向 |
| 档位切换 | 无 | **V 键 + 跳跃自动** | R 切高速后回不来 |
| `-mright` rebind | 每次松 D 重绑 Q/E | **去掉** | 完全没必要 |

## 各配置对比

### surf110.cfg — 主力配置

```cfg
cl_yawspeed 110（低速）
cl_yawspeed 293（高速）
fps_max 600
rate 30000
```

适合大多数 surf 图的通用配置。

### SURF210.cfg — 快速转向

```cfg
cl_yawspeed 210（低速）  ← 比 surf110 快一倍
cl_yawspeed 293（高速）
```

适合需要更快速转向的图。

### autoexec.cfg — 通用底包

```cfg
cl_yawspeed 60（低速）   ← 非常柔和
cl_yawspeed 293（高速）
```

作为 CS:S 启动配置，也会被其他模式加载。

### trikz.cfg — 专用模式

```cfg
cl_yawspeed 210（固定）
rate 30000
fps_max 400
```

没有 Q/E 转向系统，靠 `bind mouse1 +macro` 宏操作。
