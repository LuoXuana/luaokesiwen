# 🔄 转向系统

## Q/E 转向

Surf 中最核心的按键就是 **Q（左转）** 和 **E（右转）**，按下时会自动：

```
Q → -right; +left   （松开右转，按住左转）
E → -left; +right   （松开左转，按住右转）
```

## yawspeed

`cl_yawspeed` 控制 Q/E 转向的速度（度/秒）：

| 速度 | 数值 | 用途 |
|------|------|------|
| **低速** | 60 / 110 / 210 | 精细控制走线 |
| **高速** | 293.9535 | 360° 单帧 = 最快转向 |

## 高低速切换

配置中实现了两档速度，通过 alias 管理：

```cfg
alias "turn_speed_low"  "bind q +mTurnLeftLow; bind e +mTurnRightLow"
alias "turn_speed_high" "bind q +mTurnLeftHigh; bind e +mTurnRightHigh"
```

### 切换逻辑

```
默认 → 🚀 高速
跳   → 🐢 低速
R    → 🚀 高速
V    → 🐢 低速（手动备用）
```

## 修复的核心 Bug

原版的转向系统有一个严重问题——restore alias 全为空：

```cfg
// 原版
alias +mTurnRightHigh_restore ""    ← 空的！
```

当你按住 Q 再按 E，然后松 Q 时，restore 本该恢复 E 的状态，但因为它是空的，**E 就卡住了**。

修复方案：释放时双清 + alias 切换 bind

```cfg
// 优化版：释放时清理两个方向
alias -mTurnLeftLow  "-left; -right"
alias -mTurnRightLow "-right; -left"

// 高低速通过 alias 整体切换，不依赖 restore
alias "turn_speed_low"  "bind q +mTurnLeftLow; bind e +mTurnRightLow"
```

## 各配置的转向速度

| 文件 | 低速 | 高速 |
|------|------|------|
| `surf110.cfg` | 110 | 293 |
| `SURF210.cfg` | 210 | 293 |
| `autoexec.cfg` | 60 | 293 |
| `trikz.cfg` | 固定 210（无 Q/E 转向） | - |
