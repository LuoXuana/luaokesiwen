# 🕹️ 空移系统

## 什么是 Null Movement

空移（Null Movement）是指在 surf 中**松掉一个方向键时自动反方向补键**，让角色在坡面上保持直线滑行而不偏移。

## 原理

在 CS:S 中，同时按住 `A` 和 `D` 时，两个方向的力互相抵消，角色直线前进。空移就是利用这个原理：

```cfg
// 按下 W 时：先松 S 再按 W → 保证不冲突
alias +mfwd  "-back; +forward"
alias -mfwd  "-forward; -back"

// 按下 A 时：先松 D 再按 A → 直线不偏
alias +mleft "-moveright; +moveleft"
alias -mleft "-moveleft; -moveright"

// 按下 D 时：先松 A 再按 D
alias +mright "-moveleft; +moveright"
alias -mright "-moveright; -moveleft"

// 按下 S 时：先松 W 再按 S
alias +mback "-forward; +back"
alias -mback "-back; -forward"
```

## 为什么需要空移

| 场景 | 不用空移 | 用空移 |
|------|---------|--------|
| 直线坡 | 按 W 会微微偏移 | 按 W = 纯直线 |
| 落地 | 按 D 可能弹飞 | 按 D 稳稳贴地 |
| 大跳 | 按 Space 会左右飘 | 跳跃时 `-forward; -back` 保证稳定 |

## 已优化的配置

所有配置中空移已绑定：

```
W → +mfwd（前）
S → +mback（后）
A → +mleft（左）
D → +mright（右）
```

> D 键释放时不会再额外 re-bind Q/E（已修复原版的冗余操作）

## 常见问题

**Q: 为什么按 W+W 不会 double-forward？**  
A: 因为 `+mfwd` 里先 `-back` 再 `+forward`，即使连按也会先松掉再触发。

**Q: 空移影响正常行走吗？**  
A: 不影响。只在同时按键时发挥作用，单方向操作和原来一样。
