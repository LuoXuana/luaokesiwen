# 🦘 大跳与跳跃技巧

## Crouchjump（大跳）

### 什么是大跳

按住 **蹲（Ctrl）+ 跳（Space）** 同时触发，跳得比普通跳跃更高。

### 配置实现

```cfg
alias +Crouchjump "+duck; +jump; -forward; -back"
alias -Crouchjump "-duck; -jump; turn_speed_low"
bind "space" "+Crouchjump"
```

### 关键设计

- **按下 Space**：`+duck; +jump; -forward; -back` → 先蹲再跳，同时松方向键
- **松开 Space**：`-duck; -jump; turn_speed_low` → 落地后自动切回低速

## 档位联动（重要）

这是配置的核心设计理念：

```
┌─────────────────────────────────────────┐
│  按 R (回存点)  ────→  高速 293 跑图    │
│                          │              │
│                          ▼              │
│  遇到断层，按 Space 跳 ─→ 跳过去         │
│                          │              │
│                          ▼              │
│  松 Space (落地) ──────→ 自动切低速 110 │
│                          │              │
│                          ▼              │
│  继续按 R → 高速 ...   ←──── 循环       │
└─────────────────────────────────────────┘
```

简单来说：
- **高速跑图** → 遇到需要跳的地方 → **自动变低速** → 落地精控
- **按 R 回存点** → **自动切回高速** → 继续冲

## 跳跃类型

| 跳跃 | 操作 | 用途 |
|------|------|------|
| **普通跳** | Space（带 CJ alias） | 默认大跳 |
| **连跳 (Bunnyhop)** | Space + 鼠标同步摆臂 | 连续跳跃加速 |
| **原地大跳** | Ctrl + Space（同绑） | 跳上高台 |
| **空中转向** | 空中 + 鼠标移动 | 改变落点 |

## 注意事项

- `-forward; -back` 是为了**防止跳跃时方向偏移**
- 大跳绑在 Space，**右键 mouse2 也绑了 `+jump`**（纯跳，不带蹲）
- 有些图需要**连跳**才能过，需要配合鼠标左右摆动
