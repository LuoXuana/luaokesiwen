# 🏁 什么是 Surf

## 起源

Surf 是 CS:S / CS:GO 中的一个社区衍生玩法，玩家在特制的斜坡（ramp）上通过**摩擦力与重力平衡**来滑行，而不是在地面上走路。

## 核心概念

| 概念 | 说明 |
|------|------|
| **Ramp / 斜坡** | 供玩家滑行的斜面，分为上升坡和下降坡 |
| **Speed / 速度** | 通过合理操作维持或增加速度，是 surf 的核心目标 |
| **Turn / 转向** | 在斜坡上通过按键控制方向，保持在坡面上 |
| **Air strafe / 空中转向** | 在空中通过鼠标+按键改变方向 |
| **Drop / 掉落** | 失去对坡面的控制而掉落，通常意味着重来 |

## 基本玩法

1. 从起点出发，滑上斜坡
2. 通过 **Q/E 转向** 保持在坡面上
3. 遇到断层时 **跳（Space）** 过去
4. 在空中用 **鼠标+W/A/S/D** 控制落点
5. 到达终点即完成一张图

## Surf 与普通 CS 的区别

| 方面 | 普通 CS | Surf |
|------|---------|------|
| 移动方式 | WASD 走路 | 坡面滑行 |
| 核心技能 | 枪法、意识 | 速度控制、路线规划 |
| 死亡 | 被击杀 | 掉下坡面 |
| 目标 | 赢下回合 | 到达终点 |
| 节奏 | 快节奏对战 | 持续练习、跑图 |

## 常用术语

| 术语 | 含义 |
|------|------|
| **Tick /  Tickrate** | 服务器刷新率（100 tick = 每秒 100 次） |
| **yawspeed** | 转向速度，控制 Q/E 的转动快慢 |
| **Null movement** | 松键减速/反方向空移技术 |
| **Crouchjump / 大跳** | 蹲+跳的组合跳法 |
| **sm_teleport** | 回存点指令 |
| **sm_saveloc** | 保存当前位置 |
