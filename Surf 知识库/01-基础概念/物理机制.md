# ⚙️ 物理机制

## 速度系统

### 速度来源

```
起跳初速度 → 下坡加速 → 空中 strafe 维持 → 落地继续
```

- **下坡**：重力加速，速度增加
- **上坡**：重力减速，速度降低
- **空中**：速度基本不变（空气阻力忽略）
- **落地**：与坡面角度决定是否维持速度

### 影响速度的因素

| 因素 | 影响 |
|------|------|
| 坡面角度 | 越陡加速/减速越快 |
| 与坡面的夹角 | 夹角太大 → 失去抓地力 → drop |
| 起跳速度 | 决定了能否到达下一个坡面 |
| yawspeed | 转向速度，影响坡面控制精度 |

## 摩擦力与抓地力

在 surf 中，玩家与坡面之间存在一个「抓地带」：

- **在抓地带内**：可以控制方向，维持或加速
- **超出抓地带**：失去控制，开始滑动 → drop

> 抓地带窄 → 需要更精准的转向控制 → 低速 yawspeed
> 抓带宽 → 容错率更高 → 可用高速 yawspeed

## Tickrate 的影响

| Tickrate | 说明 |
|---------|------|
| **100 tick** | 最常见的 surf 服，需要 `cl_updaterate/cmdrate 100` |
| **102 tick** | 部分 trikz 服使用 |
| **更高** | 极少见，需要对应调整 cl_updaterate/cmdrate |

Tickrate 越高，**操作响应越精确**，但对网络要求也更高。

## 速度与 yawspeed 的关系

```cfg
// 低速 = 更精细的控制（适合复杂地形）
cl_yawspeed 110

// 高速 = 更快的转向（适合开阔地形）
cl_yawspeed 293.9535  // 360° 单帧
```

- **低速档**（110/210）：精控走线，适合多弯的图
- **高速档**（293）：快速转向，适合大弧度坡面

## 物理参数速查

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `fps_max` | 帧率上限 | 600（>600 物理可能抖） |
| `cl_yawspeed` | Q/E 转向速度 | 110~293 |
| `cl_interp` | 插值补偿 | 0（关闭） |
| `rate` | 网络带宽 | 30000（CS:S 上限） |
